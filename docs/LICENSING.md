cases and does not add permissions or restrictions. This is source-available
software with restrictions on external commercialization.

The packaged macOS app includes `LICENSE` and `docs/LICENSING.md` in
`Stillnote.app/Contents/Resources/`. In Finder, choose **Show Package Contents**
on the app to read these files.
